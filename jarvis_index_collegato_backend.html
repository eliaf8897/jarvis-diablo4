02 · Importazione planner

Importa una build da Maxroll

Incolla il link completo di un planner pubblico Maxroll, per esempio un URL che contiene /d4/planner/. Jarvis invierà il link al backend e mostrerà la risposta grezza, se il sito consente il recupero.

03 · Cosa fa questa versione
Funzioni e limiti


    

  • Controlla se il backend è raggiungibile.
    • 

  • Invia un singolo link di planner all'endpoint di importazione.
    • 

  • Mostra la risposta ricevuta, utile per verificare il formato dei dati.
    • 



Non è ancora un catalogo completo. Non importa automaticamente tutte le build/tier list di Maxroll, non traduce ancora ogni campo e non calcola la catena di farming degli oggetti. Se Maxroll cambia endpoint o blocca la richiesta, il test mostrerà l'errore: non inventeremo dati.




JARVIS è un progetto fan non ufficiale e non è affiliato a Blizzard o Maxroll. Le informazioni di gioco devono essere verificate rispetto alla patch corrente.
